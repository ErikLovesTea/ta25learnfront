# Front-endi harjutused

Vue, Vue Routeri ja Bulmaga tunnitööd: ostunimekiri ja modaalaknad.

Tunnitöö Vue põhi pärineb [õpetaja repost](https://github.com/Kasparsu/ta25alearnfront).
Varasemad commitid on ajaloos alles.

ToDo lehel saab lisamisel valida kõrge, keskmise või madala olulisuse.
Kõik kolm nimekirja näitavad olulisemaid asju eespool, vastavalt punase,
kollase ja rohelise värviga. Important sakk näitab ainult kõrge olulisusega
asju. Mõlemad lehed kasutavad sama nimekirja ja märkeruudud muudavad asja
tehtud olekut. Lehe värskendamisel taastuvad algandmed.

## Käivitamine

```sh
bun install
bun run dev
```

Ava terminalis kuvatud aadress. Tootmisversiooni koostamiseks:

```sh
bun run build
```
